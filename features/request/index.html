Why

映像を頼むとき、こんなことはありませんか。

01

誰に頼めばいいか、分からない

SNS で探しても、得意なことや、一緒に仕事をした人の感想までは分かりません。

02

いくらかかるのか、見当がつかない

同じ「30秒の動画」でも、中身しだいで何倍もちがいます。相談する前に、だいたいの金額が知りたいところです。

03

「言った・言わない」になりそうで不安

電話や SNS の DM で決めた金額・納期は、あとから確かめにくいものです。

How

依頼 → 条件の返事 →
納得して開始。

依頼を送ると、クリエイターが「この内容で受ける」「条件を出す」「お断りする」のどれかで返事をします。 金額と納期を確かめて「この条件で始める」を押すと進行中になり、決めた条件は記録に残ります。

始めたあとは、条件をあとから書きかえられません。

  • 直接依頼作品と評価を見て、プロフィールの「依頼する」から
  • 募集誰に頼むか決まっていなければ、内容と予算を出して提案を待つ
  • 予算の目安動画の種類・長さ・本数を選ぶだけで、だいたいの金額が分かる
  • メールのお知らせ返事や提案が届いたら、登録したメールアドレスにお知らせ

Record

決めたことが、残る。

金額・納期は、始めた時点の条件で残る

「この条件で始める」を押した時点の金額と納期が記録されます。あとから「聞いていない」を防げます。

誰がいつ進めたかが分かる

返事・開始・納品・入金の流れが、案件ごとに記録に残ります。見られるのはその案件の当事者だけです。

仲介の手数料はかからない

お金のやりとりは当事者どうしで直接行います。Eizo Maps は仲介の手数料をいただきません。

終わったら、お互いに評価

納品のあと、お互いに評価を書けます。次に頼む人・受ける人の手がかりになります。→ 評価について

Rules

始める前に、決まりに同意してから。

途中で金額や納期が変わることは、映像の仕事ではよくあります。あとでもめないように、クライアントは「この条件で始める」を押す前に、次の決まりを読んで同意します。クリエイターにも同じものが見えています。

For creators

クリエイターの方へ。

受ける前に、条件を出せる

依頼の内容を見て、金額や納期の条件を返事できます。例：「予算30万円なら、撮影は半日にしましょう」。

募集に、自分から提案できる

「募集を見る」から、得意な仕事に提案を送れます。見積もりは実行表で作れます。

FAQ

よくある質問

依頼にお金はかかりますか？

Eizo Maps の登録と利用は無料で、仲介の手数料もいただきません。制作の代金は、クリエイターとの間で直接お支払いください。

いくらで頼めるか分かりません。

動画の種類・長さ・本数などを選ぶだけで、予算の目安が分かります。見積もりの見方はこちらのコラムにまとめています。

誰に頼むか決まっていません。

募集を出すと、内容を見たクリエイターから条件つきの提案が届きます。届いた提案から選べます。

条件の返事に納得できないときは？

案件の中のメッセージで相談できます。始める前なら、取りやめることもできます。
