はじめる

Eizo Maps って何？

映像をつくる人（クリエイター）と、依頼する人をつなぐサイトです。作品を一か所にまとめ、取引の記録と評価を残せます。

映像制作をもっと身近に、もっと便利にするためにつくっています。はじめて依頼する人でも安心して頼めて、つくる人は仕事に集中できるように、便利な機能をこれからどんどん増やしていきます。

登録のしかた（Google・メールアドレス）

登録のしかたは2つあります。どちらも無料です。

Googleアカウントで登録する（かんたん）

  1. 右上の「ログイン」を押して、「Google で続ける」を押します。
  2. Googleの画面で、使いたいGoogleアカウントを選びます。
  3. Eizo Maps に戻ってきたら登録完了です。パスワードを新しく決める必要はありません。

Eizo Maps が受け取るのは、名前・メールアドレス・アイコン画像だけです。Googleの画面に英数字の住所（〜.supabase.co）が出ることがありますが、Eizo Maps の裏側の住所なので安心してください。

メールアドレスで登録する

  1. 右上の「ログイン」を押して、「新規登録」を選びます。
  2. メールアドレスとパスワードを入れ、使い方（クリエイター／依頼する側／両方）を選びます。
  3. 届いた確認メールのリンクを押すと、登録が完了します。

確認メールが見当たらないときは、迷惑メールのフォルダも見てください。送り主は info@eizo-maps.com です。

メールで登録したあとに、同じメールアドレスのGoogleアカウントで「Google で続ける」を押すと、同じアカウントとしてログインできます。

パスワードを忘れた

ログイン画面の「再設定メールを送る」を押すと、パスワードを決め直すためのメールが届きます。

Googleアカウントで登録した人は、パスワードはいりません。「Google で続ける」からログインしてください。

クリエイター／依頼する側の切り替え

マイページのいちばん下「アカウント」で、利用種別をいつでも変えられます。両方の使い方をしたい人は「両方」を選んでください。

お金はかかる？

今ある機能は、登録も利用もすべて無料です。

将来、仕事がもっと楽になる機能を有料で用意する予定です。ただし、お金を払った人を検索の上に出したり、評価を良く見せたりすることは絶対にしません。

プロフィール

プロフィールを作る

マイページで、表示名・肩書き・自己紹介・職種・活動エリア・キャリア年数などを入れて「保存する」を押します。顔写真やロゴは JPEG / PNG / WebP、2MB まで載せられます。

プロフィールを公開する・隠す

マイページの「プロフィールを公開する」にチェックを入れると、「クリエイターを探す」に表示されます。チェックを外せば、いつでも非公開に戻せます。

作品（ポートフォリオ）

作品を載せる（YouTube・TikTok・X・Instagram など）

「ポートフォリオ管理」で、作品を載せているページの URL を貼るだけで登録できます。

  • YouTube・Vimeo・TikTok・X・Instagram・Facebook：Eizo Maps のページの中でそのまま再生できます。縦型のショート動画もそのまま並べられます。
  • それ以外のサイト（クライアントのホームページなど）：「リンク」として載ります。見る人が押すと、そのページが開きます。
  • サムネイル（表紙の画像）が自動で付くのは YouTube と Vimeo です。ほかのサイトは、サイト名の印が付きます。
  • X・Instagram・Facebook は、投稿が「公開」になっている必要があります。鍵アカウントや友達限定の投稿は表示されません。
  • 動画ファイルそのもののアップロードはできません（動画は各サイトに置いたまま表示します）。
公開範囲の3つの違い
公開
プロフィールに表示され、誰でも見られます。
限定リンクのみ
プロフィールには出ません。共有リンクを送った相手だけが見られます。
パスワードページだけ
守秘義務のある作品向け。ストックページ（パスワード付き）にだけ並び、プロフィールにも限定リンクにも出ません。
営業先ごとに見せる作品を選ぶ（共有リンク）

「ポートフォリオ管理」の「営業用の共有リンク」で、見せたい作品だけを選んだページを発行できます。リンクを知っている人だけが見られます。営業先ごとに別のリンクを作れます。

作品を消すとどうなる？

作品を消すと、その作品を並べている共有リンクやストックページからも消えます。消す前に、どこで使っているかが表示されるので確認してください。

ストックページ（パスワード付きのページ）

ストックページって何？

パスワードを知っている人だけが開ける、あなた専用の作品ページです（1人1ページ）。守秘義務のある作品や、まだ表に出せない作品を、見せたい相手にだけ見せられます。

開いた人には「掲載作品には守秘義務があります。外部への共有・転載はご遠慮ください」と表示されます。

ストックページの作り方
  1. メニューの「ストックページ」を開き、ページの URL（半角英小文字・数字・ハイフン、3〜32文字）とタイトルを決めて作ります。
  2. 「パスワード」でパスワードを決めます。
  3. 「ページの中身」で作品を並べます。
  4. URL とパスワードを、見せたい相手に伝えます。

冒頭のあいさつは、ひな形が最初から入っています。自由に書き換えてください。消してしまっても「あいさつのひな形を入れる」で戻せます。

ストックページに作品を並べる
  • 作品棚から選ぶ：ポートフォリオ管理に登録した作品から選びます。押すとすぐ並びます。
  • 新しい URL を貼る：作品を載せているページの URL を貼ると並びます（再生できるサイトは上の「作品を載せる」と同じです）。貼った作品は作品棚にも「パスワードページだけ」として入るので、二度手間になりません。
  • 資料（企画書など）は、共有リンクを貼って並べられます。
パスワードを変えたい

ストックページの「パスワード」から、いつでも変えられます。変えると、前のパスワードでは開けなくなります。

依頼・案件

クリエイターに依頼する
  1. 「クリエイターを探す」で、職種やエリアから探します。
  2. 作品と評価を見て、プロフィールの「依頼する」を押します。
  3. 案件の内容を書いて送ると、案件として記録され、クリエイターに届きます。

金額や条件は、そのあと案件の中のメッセージで決めてください。クリエイターによっては、SNS の DM で連絡を受け付けている場合もあります。

案件の進み方

案件は「依頼中 → 進行中 → 納品済み → 入金済み → 完了」の順に進みます。誰がいつ進めたかが記録に残るので、「言った・言わない」を防げます。

見られるのは、その案件の当事者だけです。

予定と空き状況

「スケジュール」で予定を入れておくと、プロフィールに今後60日の空き状況（埋まっている日）を表示できます。予定の中身は表に出ません。

評価

評価は誰が見られる？

評価は、ログインしていない人も含めて誰でも見られます。書いた人の名前は表示されません。

評価を書く

書けるのは、実際に取引した人だけです。

  • Eizo Maps で依頼した場合：案件が「納品済み」になったら、案件管理の「相手を評価する」から書けます。
  • Eizo Maps の外で依頼した場合：取引が完了していれば、クリエイターのプロフィールの「このクリエイターの評価を書く」から書けます。取引の概要（公開されません）を添えて送り、運営が確認してから公開されます。
自分への評価に納得できない（異議申し立て）

書かれた評価を、書かれた本人が消したり直したりはできません。事実と違う・不適切だと思うときは、マイページの「あなたへの評価」から異議申し立てができます。

  • 異議申し立て中も評価は表示されたまま、「本人から異議申し立てあり」の印が付きます。
  • 運営が「あまりにも不適切」と判断した場合は削除します。
  • 削除しなかった場合は「運営の確認により掲載継続」の印が付いて公開され続けます。
自分が書いた評価を取り下げる

マイページの「あなたが書いた評価」から取り下げられます。取り下げられるのは、運営が確認中の評価か、相手から異議申し立てがあった評価だけです。

困ったとき

未払い・ハラスメントなどのトラブル

ログインして、メニューの「問題報告」から運営に知らせてください。関係する案件を選ぶと、その案件の記録が証拠としてひも付きます。やり取りのスクリーンショットなどを置いた場所があれば、URL も添えてください。

問題報告のページには、無料で相談できる公的な窓口も載せています。あわせて使ってください。
